# La Crème

Одностраничный сайт для кондитерской и кофейни **La Crème** в Махачкале. Сделан для реального заведения: меню, адрес, часы работы и контакты взяты из жизни.

**Демо:** https://your-project.vercel.app *(замени на свою ссылку после деплоя)*

## Что внутри

- Первый экран с анимированным названием и крупной типографикой
- Меню кофе с ценами и информация о десертах
- Галерея фотографий заведения
- Блок контактов: адрес, часы работы, телефон со ссылкой `tel:` и кнопка маршрута в Яндекс Картах
- Индикатор «Открыто до 22:00 / Откроемся в 09:00» по времени Махачкалы
- Курсор, плавно следующий за мышью, и «магнитные» кнопки (только на устройствах с мышью)
- Адаптивная вёрстка, от телефона до широкого экрана
- Поддержка `prefers-reduced-motion`: анимации отключаются, если так настроена система

## Стек

HTML, CSS (переменные, grid, flexbox), JavaScript без библиотек и сборщиков. Шрифты: Unbounded и Onest (Google Fonts).

## Запуск локально

Сборка не нужна. Открой `index.html` в браузере или запусти локальный сервер:

```bash
npx serve .
```

## Деплой на Vercel

1. Загрузи проект в репозиторий на GitHub
2. На [vercel.com](https://vercel.com) выбери **Add New → Project** и импортируй репозиторий
3. Нажми **Deploy**. Настройки менять не нужно, это статический сайт

Каждый `git push` автоматически обновляет сайт.

## Как обновить контент

- **Цены и меню:** блок `#menu` в `index.html`
- **Фото:** положи файлы в `images/` под именами `1.jpg`…`4.jpg`
- **Часы работы:** константы `OPEN` и `CLOSE` в начале `script.js` и блок `#contacts`
- **Цвета и шрифты:** переменные в начале `style.css`
